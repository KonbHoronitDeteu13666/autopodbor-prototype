# Автоподбор — прототип интерфейса

Кликабельный макет Android-приложения для осмотра подержанных автомобилей.
Один статический HTML-файл, без сборки и зависимостей.

Открывается на телефоне: на узких экранах макет разворачивается во весь
экран, на десктопе показывается в рамке телефона рядом со списком экранов
и пояснениями к каждому.

## Что внутри

Двенадцать экранов: каталог по маркам, выбор года, мотора и коробки,
карточка машины, список неисправностей, карточка неисправности, кузов с
очагами коррозии, пошаговая инструкция, OBD-сканер, расшифровка кода
ошибки, осмотр с рабочим чеклистом, отчёт и профиль.

Справочный контент настоящий — неисправности, нормы ЛКП, очаги коррозии и
расшифровка кодов для Toyota Camry XV40. Показания приборов, пробег и VIN
выдуманы для примера: в приложении их вводит пользователь.

Работает чеклист осмотра: отметки пересчитывают прогресс, отчёт
собирается только из заполненного.

## Локальный просмотр

Файл открывается двойным щелчком — сервер не нужен.

```
start index.html
```

## Публикация

Статический сайт без сборки. На Vercel импортируется как есть: framework
preset — Other, build command и output directory оставить пустыми.

## Статус

Прототип интерфейса, не рабочее приложение. Подключения к OBD-адаптеру,
аккаунтов и синхронизации здесь нет — они описаны в техническом задании
основного репозитория.
